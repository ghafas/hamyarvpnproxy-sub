# SOSkeyNET subscriptions

Automatically collect proxy links published in the public [@SOSkeyNET](https://t.me/SOSkeyNET) Telegram channel.

After GitHub Pages is enabled with **GitHub Actions** as the source:

- All configurations (Base64): https://ghafas.github.io/soskeynet-sub/all.txt
- Real-transfer-tested configurations (Base64): https://ghafas.github.io/soskeynet-sub/tested.txt

The workflow runs every 30 minutes and can also be started manually from **Actions**.

**Important:** `tested.txt` is intentionally empty until a real proxy tunnel is established and actual data transfer/download speed is measured. A ping or TCP connection alone is not considered a successful test.
